# SOOP MultiSync Lab 0.2.1

SOOP 라이브 방송 2~4개를 CDN 시간축에 맞추고, 그룹 전체의 안전 딜레이를 자동으로 탐색하는 실험용 Chrome 확장 프로그램입니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 `soop-multisync` 폴더를 선택합니다.

## 사용

1. 동기화할 SOOP 방송을 각각 별도 탭으로 엽니다.
2. 확장 프로그램을 열면 모든 SOOP 방송 탭이 자동으로 표시됩니다.
3. 방송별 **추가** 또는 **모두 추가**를 눌러 2~4개 탭을 등록한 뒤 **시작**을 누릅니다.
4. 처음에는 안전 딜레이 7초를 권장합니다.
5. 플레이어 위 `MultiSync` 표시와 팝업의 CDN·버퍼·오차 상태를 확인합니다.

## 현재 구현된 기능

- 최대 4개 SOOP 탭 등록
- 열려 있는 SOOP 방송 탭 자동 탐색 및 개별·일괄 등록
- SOOP Kit 멀티뷰 iframe 방송 자동 탐색 및 개별·일괄 등록
- 일반 탭 방송과 멀티뷰 방송 혼합 그룹 지원
- 일반 플레이어와 멀티뷰 각 플레이어에 상태 패널 표시
- 상단 알림은 등록·재정렬·버퍼 복구 때만 잠시 표시
- 각 SOOP 플레이어 하단에 CDN 상태·버퍼·오차·배속 표시
- HLS 재생목록 자동 감지
- `FIRST-SEGMENT-TIMESTAMP`, PTS, `EXTINF`, CDN `Date`를 이용한 공통 시간축 추정
- 가장 느린 CDN 라이브 엣지 기준 공통 플레이헤드 계산
- 큰 오차는 버퍼 내 이동, 작은 오차는 0.97~1.04배로 보정
- 버퍼링 감지 시 전체 일시정지 및 안전 딜레이 증가
- 30초 안정 시 안전 딜레이를 0.1초씩 감소
- 신뢰도 0.7 이상의 2차 분석 오프셋을 받을 수 있는 `OFFSET_EVIDENCE` 인터페이스

## 실험판의 한계

- CDN `Date`는 원본 캡처 시각이 아니라 CDN 게시 시각에 가깝습니다.
- SOOP이 HLS 요청 구조를 바꾸면 재생목록 감지가 실패할 수 있습니다.
- 서비스 워커가 재시작되면 현재 등록 그룹이 초기화됩니다.
- 멀티뷰 지원 업데이트 후에는 멀티뷰 페이지와 일반 방송 탭을 모두 새로고침해야 합니다.
- 오디오·영상 특징 분석기는 아직 연결되지 않았습니다.
- 다른 배속 확장 프로그램을 동시에 사용하면 제어가 충돌할 수 있습니다.
- 실제 방송에서 충분히 검증하기 전에는 장시간 무감독 사용을 권장하지 않습니다.

## 2차 분석 연결 형식

오디오 또는 영상 분석기가 신뢰할 수 있는 상대 오프셋을 발견하면 백그라운드로 다음 메시지를 보낼 수 있습니다.

```js
chrome.runtime.sendMessage({
  type: 'OFFSET_EVIDENCE',
  key: '123:2',
  offsetMs: 820,
  confidence: 0.91,
  source: 'audio-correlation'
});
```

신뢰도가 0.7 미만인 결과는 자동 적용되지 않습니다.
